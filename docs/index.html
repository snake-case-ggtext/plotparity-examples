plotparity examples

plotparity tests a plotnine extension against its ggplot2 original: each test plot is drawn in R and in Python, and every label, shape and colour is compared. These are live reports for five packages, including multi-round clean-room port progressions.

ggtext

plotnine-ggtext

Matches R on every feature it implements. The cases that differ use features it doesn't have yet: theme elements, <img>, R colour names, ~sub~/^sup^.

 Shannon Ellis's ggtext

ggtext_ShanEllis@9d845be (16/34 cases match R): highlights real gaps in box padding, superscript sizing, R colour names, and theme element options.

ggridges

ridgenine

Ridgeline plots for plotnine. Each case has an _r_defaults twin that passes ggridges' defaults explicitly, separating different defaults from different behaviour.

ggbeeswarm

plotnine-ggbeeswarm (Round 0 → Round 7 + Holdout)

Clean-room port of ggbeeswarm verified iteratively across 8 dev rounds (5/8 → 8/8 match) plus an unseen holdout split (3/4 match). Click any round and step with ←→ to watch layouts converge.

ggrepel

plotnine-ggrepel (Round 0 → Round 2 + Holdouts)

Clean-room port of ggrepel (6/6 dev + 4/4 unseen holdout = 10/10 match). Step through Round 0 (label overlaps) → Round 1 (tight dot spacing caught by visual review) → Round 2 (clean R-matched dot clearance).

Reading a report

  • Pick a case on the left; its R and Python renders are compared on the right, with each finding outlined on both.
  • On multi-round reports, click any round in the top bar (or any cell in Overview) and press ←→ to step through rounds in place.
  • Views: side by side s, blink b, swipe w, difference d. Hold space to flip.
  • Findings list R's value and Python's, and how far apart they are (Δ 3.09 > 2). Settings shows every check's tolerance.
  • OK marks a finding as reviewed; marks stay in your browser only.
